## About Me

I am a telecommunications security engineer and vulnerability researcher specializing in mobile network security across **2G, 3G, 4G/LTE, and 5G**.

My work focuses on identifying security weaknesses in mobile network infrastructure, telecom signaling protocols, core network functions, and cloud-native deployments.

My areas of interest include:

- Telecom protocol security and fuzzing
- Vulnerability discovery and coordinated disclosure
- Mobile core and radio access network security
- Offensive security assessments and penetration testing
- Kubernetes, OpenShift, and cloud-native security

## Publications & Technical Writing

### Fuzzing the Mobile Core: How Malformed 5G/4G Signaling Crashes Production Networks

**Published May 7, 2026 — P1 Security**

Technical research article I wrote during my time at P1 Security, examining how malformed signaling messages can trigger vulnerabilities in mobile core network implementations.

Topics covered include:

- Fuzzing of NGAP, NAS, PFCP, and core network interfaces
- Remote denial-of-service vulnerabilities in 5G AMF implementations
- Case studies of vulnerabilities discovered in Ella Core
- Security implications for mobile network resilience

**[Read the full article on P1 Security](https://www.p1sec.com/blog/fuzzing-the-mobile-core-how-malformed-5g-4g-signaling-crashes-production-networks)**
