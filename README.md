## About

Telecommunications security engineer and vulnerability researcher specializing in **mobile network security across 2G, 3G, 4G/LTE, and 5G**.

My work focuses on identifying security vulnerabilities in telecom signaling protocols, radio access and core network infrastructure, and cloud-native network functions.

**Areas of expertise:**

- **Telecom Security:** Core network, RAN, and signaling infrastructure security assessments.
- **Vulnerability Research:** Vulnerability discovery, root cause analysis, and coordinated disclosure.
- **Protocol Fuzzing:** Stateful testing, malformed signaling messages, and robustness analysis.
- **Offensive Security:** Penetration testing and attack surface analysis.
- **Cloud-Native Security:** Kubernetes, OpenShift, and containerized telecom infrastructure.
